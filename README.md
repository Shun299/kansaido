# 甘彩堂

## 概要
石川県金沢市にある架空の和菓子屋「甘彩堂」のブランドサイト兼ECサイトです。  
季節の上生菓子やどら焼き、加賀棒茶を使った和スイーツなどを扱う老舗和菓子店を想定し、商品の魅力だけでなく、店舗の歴史や和菓子作りへの想いが伝わるサイトを目指しました。

## 背景・課題
甘彩堂は、観光地に店舗を構える地域密着型の老舗和菓子屋です。  
しかし、観光客に売上が左右されやすく、冬場などの閑散期には売上が不安定になるという課題があります。
また、オンライン販売は行っているものの、商品写真やサイト全体の見せ方が弱く、ブランドの世界観や商品の魅力が十分に伝わっていない状態を想定しました。  
さらに、スマートフォンでの閲覧や購入導線にも課題があり、ユーザーが迷わず商品を選び、購入できる設計が必要だと考えました。

## コンセプト
「金沢の静けさと、手仕事の温かさが伝わる和菓子屋サイト」
余白を多めに取り、落ち着いた配色やシンプルなレイアウトを用いることで、和菓子の上品さや老舗らしい安心感を表現しました。  
また、ギフト需要にも対応できるよう、商品そのものだけでなく、梱包・送料・贈答シーンへの導線も意識しました。

## 工夫した点
- 和菓子屋らしい柔らかさ・親しみやすさ・程よい高級感を意識したデザイン
- 背景色にクリーム系、アクセントに緑を使用し、自然で落ち着いた印象を演出
- 商品一覧だけでなく、「今月のおすすめ」や「ギフト特集」を配置し、購入目的に合わせて選びやすく設計
- 店舗の歴史や和菓子作りへの想いを掲載し、ブランド価値が伝わる構成にした
- 商品カードを用いて、価格・説明・カテゴリが比較しやすいように構成
- JavaScriptで商品データを管理し、商品表示や絞り込み機能を実装

## 制作目的
フロントエンド制作の練習として、架空の和菓子屋を題材に、ブランドサイト兼ECサイトを制作しました。  
単に商品を並べるのではなく、店舗の課題を整理したうえで、ブランドの世界観・ギフト需要・スマートフォンでの使いやすさを意識して設計しております。
また、JavaScriptでは商品データをもとにカードを生成し、条件に応じた表示切り替えや絞り込み機能を実装しました。  
デザイン面と実装面の両方から、ユーザーが商品を選びやすいサイトを目指しました。
